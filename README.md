# Document Management System (doc-mgmt)

Internal document management for one organization, built with Laravel 13 and Filament 5.

## Current implementation

- Document metadata register with a unique reference number, searchable reference/title, linked category/type/department, owner, visibility, and lifecycle dates.
- Metadata-based document register filters and protected read-only metadata after a document leaves Draft.
- Dashboard expiry metrics and a watchlist of accessible documents already expired or expiring within 30 days.
- Private file uploads with SHA-256 checksums and version history.
- Version-history details include original filename, MIME type, size, checksum, uploader, lifecycle timestamps, superseded version, change notes, and current-published-version indicator.
- Authorized per-version download route with download audit records.
- Sequential/parallel review workflow, reviewer decisions, publication, replacement, and archive actions.
- Reviewer assignment notifications, reviewer pending queue, rejection-reason validation, and recent audit activity.
- Configurable expiry and next-review reminder schedules and recipient groups per document type.
- In-app database notification centre in the Admin panel.

This is an active first implementation, not yet production-ready. See [docs/ROADMAP.md](docs/ROADMAP.md) for completed Phase 4 slices and remaining release work.

## Local setup

1. Clone this repository.
2. Run `composer install`.
3. Copy `.env.example` to `.env`.
4. Create the MySQL database configured by DB_DATABASE and update DB_USERNAME / DB_PASSWORD.
5. For the first local setup only, set DMS_ADMIN_EMAIL and DMS_ADMIN_PASSWORD in your local .env file. Do not commit credentials.
6. Run `php artisan key:generate`.
7. Run `php artisan migrate --seed`.
8. Run `php artisan serve` and open /admin.

The seeder creates the default Operations department, General category, Internal Document type, and a sequential review policy. It creates the initial administrator only when DMS_ADMIN_EMAIL and DMS_ADMIN_PASSWORD are provided.

## File security

Document files are stored on the private disk under storage/app/private/documents, outside the public web root. Do not create a public storage link for this directory. Downloads must go through the authenticated, policy-checked route. Historical versions are retained as separate files and each download is authorized independently.

## Notifications and reminder scheduler

The Admin panel displays Laravel database notifications through the Filament notification bell in the top navigation. Review assignments generate notifications immediately. Expiry and next-review reminders are generated by dms:process-reminders, scheduled daily at 08:00 in the configured application timezone. Run Laravel's scheduler every minute in production. Notifications are database/in-app only; email, SMS, and push channels are not enabled. See docs/NOTIFICATIONS.md for setup and verification.
